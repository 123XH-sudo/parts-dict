# Vue 单页界面 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Jinja HTML pages with a Vue 3 SPA served by the same FastAPI process, keeping Cookie login and all current parts-dict behavior.

**Architecture:** Add JSON `/api/*` next to existing Python business logic (`search.py`, `bom.py`, `audit.py`). Vue in `web/` talks only to `/api` with `credentials: 'include'` and `X-CSRF-Token`. Vite builds into `app/static/spa`; FastAPI serves that folder and returns `index.html` for non-API GET routes. After the SPA works, delete Jinja templates and HTML form routes.

**Tech Stack:** Python 3.12, FastAPI, SQLite, Vue 3, Vite, Vue Router, no UI component library.

## Global Constraints

- Business rules stay as `docs/superpowers/specs/2026-09-16-parts-dict-design.md`.
- UI contract is `docs/superpowers/specs/2026-09-17-vue-spa-design.md`.
- One container; Node is build-time only.
- No Element Plus / Naive UI; one `web/src/styles.css`.
- Unauthenticated business API → 401 `{"detail":"未登录"}`; member hitting admin API → 403 `{"detail":"只有管理员能管账号"}`; validation → 400 `{"detail":"<中文>"}`.
- CSRF: `GET /api/csrf` (anonymous OK); writes send header `X-CSRF-Token`.
- Do not add 「记住我」 or self-service password change in this plan.
- Chinese copy only on user-facing strings.
- Tests: pytest + TestClient against `/api`; no Vue unit tests required.
- Commit after each task; do not `git push` unless asked.

## File structure

| Path | Responsibility |

```js
let csrf = "";

async function request(method, url, { json, form } = {}) {
  const headers = {};
  if (csrf) headers["X-CSRF-Token"] = csrf;
  let body;
  if (json !== undefined) {
    headers["Content-Type"] = "application/json";
    body = JSON.stringify(json);
  } else {
    body = form;
  }
  const res = await fetch(url, { method, headers, body, credentials: "include" });
  if (res.status === 401 && url !== "/api/login") {
    window.location.hash = ""; // router will send to /login in Task 6
    throw new Error("未登录");
  }
  return res;
}

export async function loadCsrf() {
  const res = await request("GET", "/api/csrf");
  csrf = (await res.json()).csrf_token;
  return csrf;
}
```
