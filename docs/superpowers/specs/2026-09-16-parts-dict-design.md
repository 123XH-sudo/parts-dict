## 1. 背景与要解决的问题

贴片时人坐在电脑前，对着嘉立创辅助焊接图，按规格（如 `10K`、`100nF`、`0603`）在若干大盒里找料袋（当前大约 12 盒，盒数以后会变）。盒内没有固定分类，料袋标签常不完整或发糊，每次都要从头翻、再三确认。

需要一本全组共用的电子字典：第一次找到某规格时登记位置，之后搜索简称就能去对应盒和格拿料；也能按盒子反查里面有哪些已登记的料。

今天要贴一块板时，不只是一个一个搜。从嘉立创导出 BOM（xlsx/csv）上传后，按盒子列出本板每一项：位号、规格、料盒位置。二极管、LED、MOS、芯片等有极性的置顶标红，避免贴反。

数量很难精确盘点，日常用「少量 / 大量」即可；重要或体积大的元件才记具体颗数。改库存不能变成每天的负担。

同事不在同一局域网也要能用。部署到已有公网服务器。每人用户名 + 密码。所有改动留修改记录。

## 2. 目标与非目标

### 2.1 成功标准

- 对着焊接图输入 `10K` 或 `0603`，1 秒内看到盒号、格号、数量档。
- 点某号盒，列出该盒已登记元件。
- 第一次翻到某袋料，用点选完成登记，无需把详细名称逐字从零打完（简称可从搜索框带入）。
- 贴完板默认不用改数量；换格子或发现空了才改，两步内完成。
- 组员在任意网络登录同一网站，看到同一份数据。
- 能查出谁在何时把某料从哪改到哪。
- 未登录不能改数据。
- 上传嘉立创 BOM 后，本板用到的规格按盒分组列出位置，无需逐个搜索。
- 二极管、LED、电解电容、MOS、IC 在清单顶部有「别贴反」提醒。

### 2.2 明确不做（本期）

- 拍照 OCR、扫码。
- 上传 Gerber / 嘉立创工程源文件自动读封装（只收 BOM 表）。
- 手机应用商店 App。手机用浏览器打开同一网站即可。
- 库存精确扣减、采购、供应商价格。
- 开放注册、第三方登录（微信 / 公司 SSO）。
- 多仓库、多工位库存隔离。本期只有一套料盒。

| 角色 | 谁 | 能做什么 |

| 管理员 | 你，第一个账号 | 查、登记、改、看历史、上传 BOM、本板贴片；给同事开/停账号；改别人密码；改盒数 |

## 4. 核心使用流程

### 4.1 日常查找（主路径）

1. 打开网站并登录。
2. 首页是大搜索框，可直接打字。
3. 输入规格、简称、详细名、`3号盒`、`第5格` 中任一段。
4. 结果行显示：简称、详细名、**3号盒第5格**、数量档（或具体数字）。
5. 有结果 → 去该格子拿。不必改数量。
6. 无结果 → 按钮「登记：{刚才输入的内容}」，简称预填搜索词。

### 4.2 按盒反查

未输入时，首页展示 **1～N 号盒**按钮（N 为当前配置的盒数，出厂默认 12）。点「3号盒」列出该盒全部已登记元件（格号排序）。用于「这个格子里到底是什么」。

### 4.3 第一次登记

翻到料袋后打开登记页（或从「登记：xxx」进入）：

- 详细名称（必填）
- 通用简称（必填，可多个，例如 `10K`、`10k`、`1002`）
- 盒号 1～N（按钮点选，必填；N 为当前盒数）
- 格号（正整数，必填，如 `5`）
- 数量：默认三选一「没有 / 少量 / 大量」；可改选「具体数字」再填正整数
- **有极性**：勾选后，本板清单置顶并显示「别贴反」
- 备注（选填：标签模糊、1 脚朝向、阴极方向、替代料）

保存后回到查找，应能立刻搜到。

### 4.4 修改

同一张表单。改位置、改档位、改简称、改备注、改极性都会写一条修改记录。删除不真删库：标记为停用，查找默认不显示，历史仍能看到。

### 4.5 本板贴片（上传 BOM）

样例文件：`docs/examples/BOM_无刷驱动_1_PCB1_12_2026-9-16.xlsx`（嘉立创导出）。

表头固定为：

| 列 | 含义 | 样例 |
|---|---|---|
| ID | 行号 | 1 |
| Designator | 位号，逗号分隔 | `R251,R42,R44` |
| Name | 规格/型号 | `10K`、`1N4148WS`、`BSC014N06NS` |
| Footprint | 封装 | `R0603`、`SOD-323_...` |
| Supplier | 常为空，或 `C25804,10kΩ` | 立创编号可作匹配键 |
| Quantity | 本板用量 | 3 |

流程：

1. 顶栏「本板贴片」→ 上传 xlsx 或 csv → 填一个短名称（默认用文件名，如 `无刷驱动 PCB1`）。
2. 程序按第 6.5 节拆行、匹配字典。
3. 打开该板页面，**不要逐个搜**：
   - 最上：**有极性，别贴反**（红条）。每行写清提醒：二极管看阴极杠、LED 看丝印、IC 看 1 脚缺口、MOS 按封装方向。
   - 其下按 **1 号盒 → N 号盒** 分组，盒内按格号。每行：位号、Name、封装简写、**几号盒第几格**、数量档。
   - 再下：**未登记**（字典没有）。点「登记」预填 Name、简称、封装。
   - 测试点、铜条等标为「不用从料盒拿」，默认折叠。
4. 同一块板可再打开，不必重复上传。重新上传同名则覆盖该板行项目。
5. 贴完不必改库存数量。

## 5. 功能清单

1. 登录 / 退出。
2. 搜索：名称、简称、盒、格，不区分大小写，空格分词（`10k 0603` 要同时命中）。
3. 按盒浏览。
4. 新建元件。
5. 编辑元件。
6. 停用元件（不当作日常删除入口，放在编辑页底部）。
7. 数量：档位或具体数字，二选一存储。
8. 修改记录列表：可按元件筛选，也可看全站最近记录。
9. 管理员：创建用户、停用用户、重置密码。
10. 导出备份：下载一份 JSON（元件 + 用户不含密码哈希 + 流水账）。
11. 上传嘉立创 BOM（xlsx/csv），生成「本板贴片」清单。
12. 清单按极性警告 / 按盒位置 / 未登记 分组。
13. 元件「有极性」标记；BOM 匹配时自动建议勾选。
14. 管理员可配置盒数（默认 12，不是写死）。

## 6. 数据设计

### 6.1 元件 `parts`

| 字段 | 类型 | 说明 |
|---|---|---|
| id | 整数，主键 | 自动 |
| name | 文本 | 详细名称 |
| aliases | 文本 | 多个简称，英文逗号分隔存储，展示为标签。匹配时拆开。约定全转小写再存一份归一化副本用于搜索 |
| aliases_norm | 文本 | 归一化后的简称串，便于搜索 |
| name_norm | 文本 | 详细名小写 |
| box | 整数 | ≥1，且 ≤ 当前配置的盒数（登记时校验） |
| slot | 整数 | ≥1，格号 |
| qty_kind | 文本 | `empty` / `few` / `many` / `exact` |
| qty_count | 整数或空 | 仅 `exact` 时有值，≥0 |
| note | 文本 | 可空 |
| polarized | 布尔 | 默认 false。true 时本板清单置顶并显示别贴反 |
| active | 布尔 | 默认 true |
| created_by | 用户 id | |
| created_at | 时间 | UTC |
| updated_at | 时间 | UTC |

界面文案：`empty`→没有，`few`→少量，`many`→大量，`exact`→具体数字。

同一「详细名 + 盒 + 格」不强制唯一：同规格可能分装两格。搜索应列出多条。  
不允许完全空白简称。至少 1 个简称。

盒数 **不写死**。存在 `settings` 表，键 `box_count`，整数，默认 **12**，允许范围 **1～99**。仅管理员可改。格号不预设上限（各盒格子数可能不同），由登记时填写。

改小盒数时：若仍有启用中的元件 `box > 新盒数`，拒绝保存并列出这些料，必须先改到合法盒号（或停用）再减盒。改大盒数立即多出按钮，无需迁数据。变更写入审计 `settings.update`。

### 6.2 用户 `users`

| 字段 | 类型 | 说明 |
|---|---|---|
| id | 整数 | |
| username | 文本，唯一 | 登录名，3～32 字符，字母数字下划线 |
| password_hash | 文本 | bcrypt |
| display_name | 文本 | 修改记录里显示的名字 |
| role | 文本 | `admin` / `member` |
| active | 布尔 | 停用后不能登录 |
| created_at | 时间 | |

第一个用户由启动脚本创建：环境变量 `ADMIN_USERNAME`、`ADMIN_PASSWORD`，角色 `admin`。只在库中尚无用户时创建一次。

### 6.3 修改记录 `audit_logs`

只追加，不更新、不删除。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | 整数 | |
| at | 时间 | UTC，页面显示本地时区 |
| user_id | 整数 | |
| username_snapshot | 文本 | 即使用户改名/删除，记录仍可读 |
| part_id | 整数或空 | 账号类操作可为空 |
| action | 文本 | `part.create` / `part.update` / `part.deactivate` / `job.upload` / `user.create` / `user.disable` / `user.reset_password` / `settings.update` |
| summary | 文本 | 给人看的一句中文，如「3号盒第5格 → 4号盒第2格」 |
| before_json | 文本 | 变更前对象，可空（创建时无） |
| after_json | 文本 | 变更后对象 |

`part.update` 的 `summary` 必须写清字段变化，不能只写「已修改」。

### 6.4 贴片任务 `jobs` / `job_lines`

`jobs`：一次 BOM 上传。

| 字段 | 说明 |
|---|---|
| id | 主键 |
| title | 短名称，如无刷驱动 PCB1 |
| source_filename | 原文件名 |
| uploaded_by | 用户 id |
| created_at | UTC |

`job_lines`：BOM 每一行（不是每一个位号拆成多行；位号保留在同一行）。

| 字段 | 说明 |
|---|---|
| id | 主键 |
| job_id | |
| designators | 原文，如 `D96,D1,D2` |
| name | BOM Name |
| footprint | BOM Footprint |
| supplier | BOM Supplier，可空 |
| quantity | 本板数量 |
| part_id | 匹配到的字典元件，未匹配为空 |
| skip_bin | true=测试点/铜条等，不进料盒分组 |
| polarized_hint | 本行是否判为有极性（见第 6.6 节） |

重新上传覆盖同一 `title` 时：删旧 `job_lines` 再建，`jobs` 更新时间。审计记 `job.upload`。

### 6.5 BOM 与字典如何匹配

对每一行生成匹配键（都转小写、去空格）：

1. Name，如 `10k`、`1n4148ws`
2. 封装简写：`R0603`/`C0603`/`LED_0603` → `0603`；其它封装保留原串前 20 字
3. Supplier 里的立创编号：`C25804,10kΩ` → `c25804`
4. Name 的单位变体：`10kΩ`↔`10k`↔`10K`，`100Ω`↔`100R`

命中规则（按顺序，命中即停）：

1. 字典简称或详细名 **完全等于** Name 的某种变体，且（封装简写一致 **或** 字典名称/简称含该封装简写）。
2. 字典简称等于立创编号 `c25804`。
3. 仅 Name 完全等于简称，全库只有 1 条——采用；多条则标「未登记（多名匹配）」，让人点选。

`10K`（电阻）与 `10K1N`（NTC）视为不同 Name，不得互相匹配。

样例板约 69 行，其中 `100nF`+`C0603` 出现多行、Supplier 不同：若字典只有一条 `100nF 0603`，这些行都指向同一格子。

### 6.6 极性（别贴反）

登记时可手勾「有极性」。BOM 行若命中下列任一条，清单也当作有极性（即使字典还没勾）：

**要提醒**

- 位号拆开后前缀为 `D`、`LED`、`Q`、`EC`
- Name 含：`1N`、`SS34`、`SS54`、`SMAJ`、`BZT`、`LED`、`MOS`、二极管常见型号
- 封装含：`SOD-`、`SMA_`、`LED`、`TO-220`、`LQFP`、`SOIC`、`TSSOP`、`SOT-23`、`POWERVDFN`、`CAP-TH`（插件电解）

**不要提醒（即使位号是 U）**

- Name/封装含：`Test-Point`、`铜条`、`WAFER`、`CONN`、`DB2ERC`
- 位号前缀 `R`、`C`（贴片电容默认无极性）、`L`、`TP`、`CN`、`SW`、`X`、`NTC`

提醒文案按类型固定，不让用户每次写：

- 二极管 / 稳压管：`别贴反：阴极有杠/斜角，对丝印。`
- LED：`别贴反：看封装缺口或丝印极性标。`
- MOS / 三极管（Q）：`别贴反：按封装方向，G/D/S 不要转 180°。`
- IC（U 且未被排除）：`别贴反：1 脚对丝印圆点或缺口。`
- 电解（EC 或 CAP-TH）：`别贴反：负极（壳体条纹/短脚）对丝印阴影；长脚一般是正极。`

## 7. 搜索规则

- 输入去首尾空格，按空白分成关键词。
- 每个关键词都要命中（AND）。
- 命中字段：详细名、任一简称、`{box}号盒`、`第{slot}格`、纯数字盒号或格号。
- 大小写不敏感。`10K` 与 `10k` 相同。
- 停用元件默认不出现。
- 空搜索：不列出全部元件（避免刷屏），只显示当前配置的 N 个盒按钮。
- 结果排序：简称或名称以关键词开头的靠前，其次按盒号、格号。

## 8. 界面

电脑为主（对着焊接图），页面要能在手机浏览器勉强能用（搜索框够大）。

1. **登录页**：用户名、密码、可选「记住我」。
2. **查找页（登录后首页）**：搜索框、结果列表、N 个盒按钮、无结果时的登记入口。顶栏：当前用户、本板贴片、修改记录、账号（管理员才显示）、退出。
3. **登记/编辑页**：第 4.3 节字段。盒号为当前 N 个按钮。数量默认档位；切换到具体数字时出现数字框。
4. **修改记录页**：时间倒序表格：时间、人、动作、对象、摘要。可按元件 id 过滤。
5. **账号页（管理员）**：用户列表、新建、停用、重置密码；**盒数**（数字，保存后全站按钮立刻变）。
6. **本板贴片页**：上传 BOM；历史任务列表；某板的分组清单（极性 / 按盒 / 未登记 / 不用拿）。

视觉要求：查找页搜索框最大；盒号/格号在结果里用加重字体；极性块用警告色但不用大段装饰。中文界面。顶栏增加「本板贴片」。

## 9. 架构

单机 Web 应用，部署在已有公网服务器上。

```
浏览器  --HTTPS-->  Nginx（已有或容器内）  -->  FastAPI  -->  SQLite 文件
```

- 所有写操作先校验 Session，再改 `parts`，再插入 `audit_logs`，同一事务。
- 两人同时改同一条：后提交覆盖，两条审计都保留（last write wins）。不做复杂锁。
- 只读搜索无审计。
- SQLite 文件放 Docker volume，随容器重启保留。
- 应用不存业务数据到浏览器。本地仅 Session Cookie。

并发：小组使用，SQLite WAL 模式足够。

- `SECRET_KEY`：必填，随机长字符串
- `ADMIN_USERNAME` / `ADMIN_PASSWORD`：仅首次初始化
- `TZ`：默认 `Asia/Shanghai`，页面时间按此时区显示

## 11. 错误与安全

- 用户名或密码错：笼统提示「用户名或密码不对」，不区分哪一项。
- 未登录访问业务页：跳转登录。
- 组员打开账号管理：403 页面。
- 登记缺必填：页面留在表单并标红，不写库、不写审计。
- 盒号非 1～当前盒数、格号 < 1、具体数量非整数：同上。
- 管理员把盒数改到小于已有元件占用的最大盒号：拒绝，并列出那些料。
- 服务器或数据库失败：页面明确「没存上，请重试」，禁止显示成功。
- BOM 不是 xlsx/csv、没有 `Designator`/`Name`/`Footprint` 表头、或行数为 0：页面说明「请用嘉立创导出的 BOM」，不写库。
- 单文件不超过 2 MB。
- 所有对外表单 CSRF：Session 内 CSRF token。

## 16. 决策摘要（避免歧义）

| 问题 | 决定 |
|---|---|
| 主要使用场景 | 电脑前对着嘉立创辅助焊接图 |
| 主要检索词 | 规格（阻值/容值/封装），兼位号式简称 |
| 盒现状 | 无规律，标签常不清 |
| 建档方式 | 边找边记，不先全量打字 |
| 位置 | 盒号 1～N + 格号；N 默认 12，管理员可改（1～99） |
| 数量 | 没有/少量/大量，大件可具体数字；贴片不强制扣减 |
| 访问 | 公网服务器，非仅局域网 |
| 身份 | 用户名+密码，管理员开账号，不开放注册 |
| 冲突 | 后写覆盖 + 审计两条都留 |
| 客户端 | 浏览器，不做独立 App |
| 本板清单 | 上传嘉立创 BOM（xlsx/csv），按盒分组，不逐个搜 |
| BOM 格式 | 表头 Designator / Name / Footprint / Supplier / Quantity |
| 极性 | 二极管、LED、电解、MOS、IC 置顶提醒；电阻电容 NTC 不提醒 |
