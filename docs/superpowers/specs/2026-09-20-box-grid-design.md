工位对照实物元件盒拿料。首页要用大卡片列出各盒；点进一盒看到与实物相同的行列格子。每盒行列可在该盒页面上改，默认 8 列 × 6 行（48 格）。

---

## 1. 要解决的问题

- 首页盒号是一排小按钮，太长、不好点。
- 从登记页「返回查找」后，首页经常不像有盒子（盒列表依赖空查询接口，慢或失败就是空白）。
- 点进某盒后是纵向表格，对不上手上「一行 8 格、六行、第二行 9–16」的盒子。

---

## 2. 目标与非目标

### 2.1 成功标准

- 打开 `/`（含「返回查找」、保存后回来）立刻能看到盒卡片，不依赖搜索接口成功。
- 盒卡片较大，多列排布（大约每行 3～4 个），标明盒号和占用（如 12/48）。
- 点「3号盒」进入 `/boxes/3`：默认 8 列 × 6 行；空格可点去登记并预填盒号格号；有料显示简称，点进去改。
- 在该页改列、行后格子立刻按新尺寸重画，且只改这一盒。
- 搜 `10K` 等仍是表格；清掉搜索词回到盒卡片。

### 2.2 本期不做

- 账号页里编辑各盒行列（只在盒子页上改）。
- 拖拽改格子、打印标签、3D 盒盖图。
- 强制所有现有料的格号 ≤ 列×行（改小后多出的料列在格子下方）。
- 改 `parts` 表结构。

## 3. 页面与路由

| 路由 | 内容 |
|---|---|
| `/` | 搜索框 + 盒卡片；有搜索词则结果表（或空结果「登记：词」） |
| `/boxes/:n` | 第 n 号盒的格子图 |
| `/parts/new?box=&slot=` | 现有登记表，预填盒号格号 |
| `/parts/:id/edit` | 现有修改表 |

顶栏「登记」仍去 `/parts/new`。格子页有「返回查找」链到 `/`。

编号：左上为 1，从左到右填满一行再换下一行。8×6 时第一行 1–8，第二行 9–16，最后一行 41–48。

列、行各允许 1～24。未配置的盒：`cols=8`，`rows=6`。

---

## 4. 格子交互

- 空格：浅底 + 格号；点 → `/parts/new?box={n}&slot={k}`。
- 有料：简称（过长省略）、有极性沿用现有红色；点 → `/parts/{id}/edit`。
- 页上两个数字框：列、行。改完防抖保存 `PUT /api/boxes/{n}/layout`，成功则重画。非法值提示中文错误，不写库。
- 该盒启用中的料若 `slot > cols*rows`，在格子下方列出（简称、格号、改）。

登记表：若 query 带 `box`、`slot` 且为合法数字，打开时填入对应字段。

---

## 5. 数据与 API

`settings` 表键 `box_layouts`，值为 JSON 对象：

```json
{"3":{"cols":8,"rows":6},"5":{"cols":6,"rows":8}}
```

没有该键或某盒没有条目 → 该盒 8×6。不改 `parts`。备份已导出全部 `settings`，无需改备份格式。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/boxes` | 登录。`{boxes:[{n, cols, rows, used, total}, ...]}`。`total=cols*rows`，`used` 为该盒全部 `active` 元件条数（含格号超出格子的）。盒个数仍由 `box_count` 决定。 |
| GET | `/api/boxes/{n}` | 登录。盒号不在 1～盒数 → 404。`{n, cols, rows, slots:[null 或 part_result, ...], overflow:[part_result,...]}`。`slots` 长度 `cols*rows`，下标 0 为第 1 格。 |
| PUT | `/api/boxes/{n}/layout` | 登录 + CSRF。body `{cols, rows}` 整数 1～24。写入 `box_layouts`，审计 `settings.update`，summary 写清「3号盒 8×6 → 6×8」。 |

未登录 401。校验失败 400，中文 `detail`。组员可以改布局（与登记元件相同权限）。

首页卡片：`session.user.box_count` 先画出 1～N 号盒（默认 8×6、占用先空或「—」），`GET /api/boxes` 返回后再补占用数字。接口失败卡片仍在。
