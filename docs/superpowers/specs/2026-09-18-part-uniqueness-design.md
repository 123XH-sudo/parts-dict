# 元件唯一性：一种料只占一格

日期：2026-09-18  
状态：待你确认后写实现计划  
产品名：料盒字典  
仓库：`/home/skez/Downloads/parts-dict`  
前置：`docs/superpowers/specs/2026-09-16-parts-dict-design.md`、`docs/superpowers/specs/2026-09-17-vue-spa-design.md`

本设计修正原业务说明中「同规格可能分装两格」：启用中的元件，按详细名或简称判定为同一颗时，只允许占一个格子。格子占用规则不变（一格仍只能放一种料）。

---

## 1. 要解决的问题

登记元件时，同一颗料可能被写进两个格子。查找会出两条，工位不知道拿哪一格。

需要：已经登记过的元件不能再登记；提示里写出现有位置。

---

## 2. 目标与非目标

### 2.1 成功标准

- 用已有详细名再保存 → 400，不能写入。
- 用已有某一个简称再保存（详细名可以不同）→ 400，不能写入。
- 提示包含现有位置，例如「这颗料已在 3号盒第5格，不能重复登记。」
- 高精度与普通电阻这种相近但不相同的料可以并存，例如简称 `10KR高精度电阻` 与 `10KR`。
- 修改自己这条不误拦；改成与另一条启用料冲突则拦住。
- 格子占用检查仍生效。

### 2.2 本期不做

- 数据库唯一索引、表结构迁移。
- 输入过程中的实时查重（只在保存时拦）。
- 提示里区分「撞的是详细名还是简称」。
- 给已存在记录做跳转链接。
- 清理库里已经重复的历史数据。
- 按封装、精度、阻值拆开的智能去重。

---

## 3. 判定规则

只检查 `active=true` 的元件。已停用的不算占用，可以重新登记。

比较前使用现有 `normalize()`：去掉空格和 `Ω`/`ω`，再转小写。

两条启用中的料视为同一颗，当且仅当：

1. `name_norm` 完全相同，或
2. 拆开后的某一个 `aliases_norm` 与对方某一个简称完全相同

不做包含匹配：`10kr` 与 `10kr高精度电阻` 不是同一简称。

比较时排除正在保存的那条 `id`（新建没有 id，不排除）。

新建（`POST /api/parts`）和修改（`PUT /api/parts/{id}`）都执行。

---

## 4. 保存时的检查顺序

与现有格子占用写在同一处（`app/main.py` 的创建/更新接口），不改前端提交逻辑。

1. 字段校验（名称、简称、盒号、格号、数量）失败 → 原有错误。
2. 元件已存在（本节规则）→ 400：`这颗料已在 {位置}，不能重复登记。`  
   `{位置}` 用现有 `location_text`，如 `3号盒第5格`。
3. 格子已被占用 → 原有错误：`{位置}已经有 {简称}，一格只能放一种料。`
4. 两道都过 → 写入，并记审计。

名称/简称和格子同时冲突时，先报元件已存在。

登记页、修改页继续把 API 的 `detail` 显示在现有红色错误行。不跳转、不写入。

---

## 5. 实现要点

- 新增查找函数（与现有 `occupied(box, slot)` 并列），按上面规则找冲突的启用料；多条命中时取 `id` 最小的一条，位置按它来写。
- 不改 `parts` 表，不加唯一约束。
- 简称仍存在一列里，按现有 `parse_aliases` / `aliases_norm` 拆开比较。
- 前端 `PartForm.vue` 无需新交互；现有 `error` 展示即可。
